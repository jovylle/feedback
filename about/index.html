About this feedback page

This is a small static feedback portal for ideas, bugs, and requests. It is designed to collect messages for projects like d1g.uk and Sunflower Land digging, but it can be used for many purposes.

  • Quick feedback form with no account required
  • Supports query params like ?otherinfo=asdasd&for=sfl
  • Safety-first: stay on the page during submission

If you load /?otherinfo=...&for=..., those values are attached to the submission as hidden fields.
