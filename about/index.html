About this feedback page

This is a small static feedback portal for ideas, bugs, and requests. Load the root URL for general feedback, or add a context slug to make the page clearly dedicated to a specific tool.

  • General feedback lives at /
  • Context-specific feedback uses ?context=...
  • The visible label is derived from the slug automatically

If you load /?context=..., the page title, banner, and submission data all reflect that context.

Recommended link for your tool: https://feedback.uft1.com/?context=sunflower-land-digging-assistant

Examples: ?context=chat-widget becomes Chat widget and ?context=portfolio becomes Portfolio.

Backward compatible: the old ?for=... link still works.
